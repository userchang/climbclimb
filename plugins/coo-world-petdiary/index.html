桌宠日记 v0.3.4 · 2026-10-30（最新 v0.3.7）

Coopanion 桌宠 World 插件 · npm: coo-world-petdiary
前往 npm 安装 / 查看包信息

源码：github.com/userchang/coo-world-petdiary

这是什么

Coopanion 桌宠（Coo）的日记 World 插件：让 Coo 用 diary_append 直接写日记，用户在扩展面板里按公开本 / 私密本回看，并可一键构建对外静态分享页。底层解析、入库、审计链与条目指纹校验由独立 Python 后端（仅标准库，无第三方依赖）完成。

功能

  • 公开本 / 私密本双册管理：public 可进入对外分享页，private 仅自留
  • 支持日常 / 心情 / 想法 / 计划 / 健康 / 游戏 / 交际分类标签，留空按关键词推断
  • 三区浏览面板：最近条目、今日写作状态、各册与审计计数，支持一键生成静态浏览页
  • 只追加审计链与条目指纹完整性校验，删除同样写留痕审计
  • 睡前检查时刻可配置（bedtimeCheck），改动后提醒 Coo 对齐「睡前检查」闹钟

安装

  1. 在 Coo 扩展目录安装（或直接在扩展页安装）：npm install coo-world-petdiary
  2. 在 Coopanion 扩展配置中启用 worlds.pet-diary，默认配置全部留空即可开箱即用
  3. Windows 包内自带嵌入式 Python 与后端脚本，首次打开面板或调用工具会自动初始化默认日记库

需要什么

  • Node.js 22+ 与 Coopanion（Cortico world API 6）
  • Windows 无需额外装 Python；非 Windows 平台需系统 PATH 中有 Python 3.8+
