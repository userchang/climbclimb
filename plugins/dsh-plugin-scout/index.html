这是什么

装进 DeepSeek Harness 后，它会像一个每天上班的情报员：到点自动采集当天的技术情报 （GitHub Trending、Hacker News、B 站等），汇总成一份中文日报，推送到你指定的飞书群机器人。 采集与推送全部由本机完成，凭据只经环境变量传给运行进程，不进日志、不进返回值。

功能

  • 每日定时采集 + 汇总 + 飞书推送，支持多个渠道、多份 Webhook
  • 错过时点自动补跑，跨零点的旧日期自动换算重试
  • 设置页待办清单：缺什么凭据、去哪拿、怎么验证，一条条列给你
  • 峰时段照常运行（只提示不拦截），运行状态与上次结果面板可见
  • 演练模式：全流程走一遍但不真的发消息

安装

  1. 下载并解压上面的 zip 到任意目录（路径别带空格）
  2. PowerShell 里执行：powershell -ExecutionPolicy Bypass -File install.ps1
  3. 重启 DeepSeek Harness，在 设置 → 情报员日报 里按待办清单配好凭据
  4. 先开「演练」跑一次，确认日报没问题再正式推送

需要什么

  • Windows + DeepSeek Harness（desktop profile）
  • Python 3.10+（系统 PATH 里有 python 或 python3 即可）
  • 一个飞书群的自定义机器人 Webhook；GitHub token / DeepSeek Key / B站 SESSDATA 按需选配
